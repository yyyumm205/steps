# RingFitness Steps 0.9.4

日期：2026-09-28。

本版收敛同一手机安装新版“步数采集”和旧版RingFitness时的戒指搜索与连接所有权。采集、保存、上传、九种运动、可选Polar H10及研究数据契约沿用0.9.3。

## 本版修复

- 搜索前读取本机系统级GATT连接。系统能识别到Ringo时，页面直接说明戒指正由本机其他App使用；已登记戒指即使暂时没有蓝牙名称，也可用MAC地址识别。
- 同机安装旧版RingFitness且搜索失败时，页面提供“前往系统设置停止旧版”。用户先在旧版完成当前采集，再在系统页面点“强行停止”；返回新版后自动重新搜索。
- 扫描日志分别记录回调数、可见设备数和Ringo数；扫描器不可用、蓝牙资源不足和短时间搜索过于频繁会显示对应的恢复步骤。
- 未收到Ringo广播时，页面区分可执行的恢复步骤：戒指放入充电盒10秒后完全取出，并关闭曾连接它的其他手机蓝牙。
- 新版在空闲页面退到后台时释放GATT，降低它对另一手机或App的占用；采集、停止确认、下载和本地保存阶段继续持有连接，保护进行中的记录。
- 页面快速离开并返回时，新的页面租约会取消旧的异步释放，避免刚恢复页面又断开连接。

这些恢复动作只调整连接，不发送START或STOP，也不清除App、戒指或已有session数据。Android应用无法直接停止另一个App或关闭另一部手机的蓝牙，因此对应操作由用户在明确提示下完成。

- Android JVM全量788项通过，0失败、0跳过。
- API 31模拟器中，准备页与连接所有权定向测试共34项通过；另外安装师兄原版0.5.3后，实际包可见性检查1项通过。测试覆盖旧版安装提示、系统入口、扫描期间连接竞争、短暂GATT残留、发现戒指后清除恢复入口、空闲离开释放、立即返回续租以及在途下载保持连接。

- Release与`lintVitalRelease`构建通过，正式APK经zipalign、v3签名、版本元数据和模拟器安装读回核验。
- 华为ELS-AN10诊断确认两款App可以同时安装，蓝牙与扫描权限正常；停止本机旧版后系统GATT连接数为0，但扫描仍未收到Ringo广播。该次现象指向戒指未广播或仍由其他手机占用，需在关闭其他手机蓝牙并用充电盒唤醒后完成真机恢复核对。
