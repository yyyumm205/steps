# RingFitness Steps 0.9.0

日期：2026-09-27。

状态：软件实现、跨端回归与API31模拟器交付检查完成；真实H10与双设备长时能力继续按设备矩阵验收。

## 本版功能

- 首页选择走路、跑步、羽毛球、足球、篮球、网球、乒乓球、排球或力量训练，每段对应一种运动。
- 走路和跑步保留计步器清零及参考总数填写；其他七种运动停止后直接选择保存方式，研究端记为“不适用”，数字为空。
- 九种运动均可选 Polar H10，每段默认关闭。沿用原版实时 HR/RR、就绪检查和断线重连；设备身份随本段固定。
- 心率带断开时戒指采集继续，心率缺口如实保留。重开 App 恢复当前段，完成后新段恢复默认关闭。
- 保留“保存并上传／暂存到戒指／放弃本段”。暂存时已收到的心率保存在手机，戒指文件等待手动下载；首次打包后两者进入同一冻结 ZIP。
- Python 导入器升级至 0.3.0，接受新 manifest v8 并兼容 v2–v7，输出运动分类、参考适用性、HR/RR CSV 和心率质量信息。

用户名、戒指、运动及所选 H10 在开始时固定。每段独立命名、上传和去重；已冻结历史包保持原字节。H10 时间为手机接收时间，研究输出明确注明来源。

## 硬件验证范围

本轮没有可用的真实 H10，尚未验证新版本在真实手机上同时连接戒指与 H10、锁屏采集、心率断连恢复及同包云端读回。现有华为约 3 小时戒指链路证据属于 0.8.18 及此前版本，详见 E41–E45。

硬件齐备后，以短采验证以上双设备流程，再记录长时电量、数据覆盖与传输耗时。10 小时双设备采集、华为／小米具体机型和不同固件组合均以实测结果为准。当前 H10 范围是实时 HR/RR；ECG、胸带离线回补和其他品牌另行规划。
