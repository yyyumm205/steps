# 步数采集 App 使用说明

适用版本：0.9.4

## 第一次使用

1. 打开“步数采集”，填写研究者分配的用户名，选择戒指佩戴位置。
2. 点击“下一步”，允许所需权限。将戒指完全取出充电盒、放在手机旁，等待搜索结果，再点击研究者发给你的戒指。
3. 回到首页，等待设备状态显示“可以开始”。App会记住这些信息。

空闲时可从首页“设置”查看或更换用户名、佩戴位置和戒指。当前一段尚未保存到手机时，先处理首页显示的任务。更换用户名只影响之后的新段；首页与记录页显示当前用户的记录，换回原用户名即可查看原记录。已安排上传的旧记录继续归属于采集时的用户。

允许通知可查看采集和上传进度。设置中若出现“允许后台运行”，按提示允许后台运行，方便锁屏后继续处理。

同一枚戒指一次由一台手机中的一个App连接。手机可以同时安装“步数采集”和旧版RingFitness；切换手机或App前，先在当前App结束并保存本段。空闲时将“步数采集”切到后台会释放戒指连接；正在采集、停止确认或保存戒指文件时会继续连接，以保护本段数据。

## 开始一段采集

1. 在首页选择本段运动：走路、跑步、羽毛球、足球、篮球、网球、乒乓球、排球或力量训练。
2. 戴好戒指。走路和跑步还需戴好计步器，站定并将计步器清零；其他运动无需计步器。
3. 九种运动均可选用心率带，每段默认关闭。如需心率，在同一页点击“启用 Polar H10”，搜索并连接，等待显示“Polar H10 已就绪”；开始前也可点击“关闭心率带”。
4. 点击“开始采集”。看到“正在采集”后开始活动。

每段只选一种运动。切换时先结束当前段，完成保存后重新选择；走路和跑步每段分别清零。

H10 由手机实时接收心率和心搏间期（HR/RR），请让手机保持在可连接范围内，并允许 App 后台运行。心率连接中断时会自动尝试恢复，戒指采集继续；恢复后从新收到的数据继续本段，中断期间保留缺口。当前版本的胸带采集采用实时接收方式，离线回补属于后续功能。每段开始前按需重新启用心率带。

## 结束一段采集

1. 站定，将戒指靠近手机，点击“结束采集”。
2. 走路和跑步会显示步数输入框，填写计步器的本段总数；其他运动直接等待停止确认，无需填写数字。App同时核对戒指状态。
3. 确认完成后，处理按钮会在原页出现。选择一种处理方式：

| 选择 | 接下来怎么做 |
| --- | --- |
| 保存并上传 | 保持戒指靠近手机，等待页面确认数据已保存在手机。之后可回首页；联网时App继续上传 |
| 暂存到戒指 | 本段信息、已填步数和已收到的心率保存在手机，戒指数据暂留戒指。稍后从首页或记录中点击“下载并上传”，使用同一枚戒指完成保存。在此之前不能开始下一段或更换用户、佩戴位置和戒指 |
| 放弃本段 | 再次确认后结束本段，清理本段在手机中的数据文件和任务，包括已收到的心率；其他记录保留，本段退出上传与研究统计 |

走路或跑步时，如果计步器没有可填写的数字，选择“放弃本段”。其他运动正常保存即可。

## 查看记录

首页的记录入口显示每段的当前状态：

- “已上传”：本段已经完成上传。
- “正在上传”：数据已保存在手机，App正在上传。
- “已保存，等待上传”：保持网络可用，App会继续上传。
- “已保存，稍后上传”：这是旧版本保留的记录，点击“上传”后继续。
- “上传失败”：点击“重试上传”。
- “上传记录需要研究者核对”：文件仍保存在手机，停止重复上传；将页面截图发给研究者，避免云端出现重复文件。
- “暂存到戒指”：准备好原来的戒指后，点击“下载并上传”；也可选择放弃。

上传在后台进行。原始数据保存到手机后，可以开始下一段，无需等待云盘完成。

## 遇到问题

| 情况 | 操作 |
| --- | --- |
| 戒指未连接 | 将戒指完全取出充电盒并靠近手机，按页面点击“重新连接” |
| 搜索不到戒指 | 将戒指放入充电盒10秒后完全取出，关闭曾连接它的其他手机蓝牙，再点击“重新搜索” |
| 同一手机装有旧版RingFitness | 先在旧版结束并保存正在进行的采集。新版搜索页出现“前往系统设置停止旧版”时，点击它并在系统页面点“强行停止”，返回后会自动重新搜索 |
| 心率带搜索或连接失败 | 戴好 H10 并靠近手机，在原页重新搜索或连接；本段无需心率时，可在开始前点击“关闭心率带” |
| 心率数据保存中断 | 戒指采集继续，结束按钮仍可使用。按提示检查手机空间，结束后在原页重试保存；保留 App 数据 |
| 开始或结束仍在确认 | 保持戒指靠近手机，等待页面更新；出现“重新检查”时点击它 |
| 保存失败 | 在当前页面重试；走路、跑步还需保留计步器数字，保存成功后再清零 |
| 下载中断 | 保持同一枚戒指有电并靠近手机，在当前任务中继续下载 |
| 上传失败 | 检查手机网络，在记录中点击“重试上传” |
| 上传记录需要研究者核对 | 不要反复点击上传；保留App数据并将页面截图发给研究者 |
| 数字填错 | 首次上传前，使用记录中的“修改步数”；入口已经关闭时，把采集日期、时间和正确数字发给研究者 |
| App退出或手机重启 | 重新打开App，按首页当前任务继续 |

搜索恢复不会发送开始或结束命令，也不会删除手机或戒指数据。出现无法继续的状态时，保留App和本段所用设备的当前信息，将页面截图发给研究者。不要卸载App或清除应用数据。
