# 步数采集 App 使用说明

适用版本：0.8.9-upload-guard

## 第一次使用

1. 打开“步数采集”，填写研究者分配的用户名，选择戒指佩戴位置。
2. 点击“保存并连接戒指”，允许所需权限，再选择研究者发给你的戒指。
3. 回到首页，等待设备状态显示“可以开始”。App会记住这些信息。

空闲时可从首页“设置”查看或更换用户名、佩戴位置和戒指。当前一段尚未保存到手机时，先处理首页显示的任务。

允许通知可查看采集和上传进度。设置中若出现“允许后台运行”，按提示允许后台运行，方便锁屏后继续处理。

## 开始一段采集

1. 在首页选择“走路”或“跑步”。
2. 戴好戒指和计步器，站定，将计步器清零。
3. 点击“开始采集”。看到“正在采集”后开始活动。

走路和跑步分别采集。切换活动时，先结束当前段；完成保存后重新选择活动并清零。

## 结束一段采集

1. 站定，将戒指靠近手机，点击“结束采集”。
2. 等待App确认结束，读取计步器数字并填写本段总步数。
3. 选择一种处理方式：

| 选择 | 接下来怎么做 |
| --- | --- |
| 保存并上传 | 保持戒指靠近手机，等待页面确认数据已保存在手机。之后可回首页；联网时App继续上传 |
| 暂存到戒指 | 本段步数会保存在手机，采集数据暂留在戒指。稍后从首页或记录中点击“下载并上传”，并使用同一枚戒指完成保存。在此之前不能开始下一段或更换用户、佩戴位置和戒指 |
| 放弃本段 | 再次确认后结束本段；本段不会上传或计入研究 |

如果计步器没有可填写的数字，选择“放弃本段”。

## 查看记录

首页的记录入口显示每段的当前状态：

- “已上传”：本段已经完成上传。
- “正在上传”：数据已保存在手机，App正在上传。
- “已保存，等待上传”：保持网络可用，App会继续上传。
- “已保存，稍后上传”：这是旧版本保留的记录，点击“上传”后继续。
- “上传失败”：点击“重试上传”。
- “上传记录需要研究者核对”：文件仍保存在手机，停止重复上传；将页面截图发给研究者，避免云端出现重复文件。
- “暂存到戒指”：准备好原来的戒指后，点击“下载并上传”；也可选择放弃。

上传在后台进行。原始数据保存到手机后，可以开始下一段，无需等待云盘完成。

## 遇到问题

| 情况 | 操作 |
| --- | --- |
| 戒指未连接 | 将戒指靠近手机，按页面点击“重新连接” |
| 开始或结束仍在确认 | 保持戒指靠近手机，等待页面更新；出现“重新检查”时点击它 |
| 保存失败 | 保留计步器数字，在当前页面重试；成功前不要清零 |
| 下载中断 | 保持同一枚戒指有电并靠近手机，在当前任务中继续下载 |
| 上传失败 | 检查手机网络，在记录中点击“重试上传” |
| 上传记录需要研究者核对 | 不要反复点击上传；保留App数据并将页面截图发给研究者 |
| 数字填错 | 首次上传前，使用记录中的“修改步数”；入口已经关闭时，把采集日期、时间和正确数字发给研究者 |
| App退出或手机重启 | 重新打开App，按首页当前任务继续 |

出现无法继续的状态时，保留App、戒指和计步器当前信息，将页面截图发给研究者。不要卸载App或清除应用数据。
