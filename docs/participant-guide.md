## 第一次使用

1. 按研究者说明安装“步数采集”，填写分配给你的被试编号和戒指佩戴位置。
2. 点击“保存并连接戒指”，按手机提示允许所需权限，选择研究者发给你的戒指。
3. 等待连接检查完成，点击“进入采集”。App会记住编号、佩戴位置和戒指。

首次在研究者指导下完成一次操作。以后打开App，先核对编号与佩戴位置，再处理当前页面提示的任务。

## 每次开始

1. 按约定佩戴戒指和计步器，保持手机与戒指靠近，站定后将计步器清零。
2. 点击“开始采集”，保持站定，等手机显示“正在采集”后开始活动。
3. 按研究安排正常生活，走路、跑步和休息可以自然切换。计步器在这一段内持续记录，结束保存后、下一次开始前再清零。

## 每次结束

1. 站定，将戒指靠近手机，点击“结束采集”，等待App确认戒指停止。
2. 等计步器数字稳定，填写显示的本次总步数，核对后点击“保存并上传”。
3. 保持戒指靠近手机，等待戒指数据下载。页面确认数据已保存在手机后，可以返回首页；有网络时App继续上传。
4. 查看本次记录。显示“已上传”表示云盘已接收；若仍在等待或需要重试，按下面的恢复方法处理。

## 遇到问题

| 页面或实际情况 | 请这样做 |
| --- | --- |
| 连接失败、开始或结束状态待确认 | 将戒指靠近手机，按页面重新连接或检查。保留当前计步器读数；状态持续无法确认时联系研究者 |
| 保存失败 | 保留计步器读数，在原页面重试；成功前避免清零计步器 |
| 下载中断 | 保持戒指有电并靠近手机，在当前记录中恢复下载。先完成这一段，再开始新采集 |
| 等待上传或上传失败 | 恢复手机网络并重新打开App；显示失败时点击该记录的“重试上传” |
| 忘记清零、计步器意外归零或读数无法辨认 | 点击“读数有问题？”，选择“数字可能不准确”或“无法提供读数”，说明原因后保存 |
| 数字保存后发现填错 | 保留本次记录，告知研究者采集日期、时间及正确数字，由研究者核对 |
| App意外退出 | 重新打开，按当前记录继续。若出现“戒指数据需要检查”，保留设备与App数据并联系研究者 |

采集和恢复期间请保留App数据、戒指记录及未确认保存的计步器读数。手机、戒指、计步器的充电与使用安排按研究者发放说明执行；已验证时长及使用条件以上表为准。
