# RingFitness Steps 0.9.2

日期：2026-09-28（Asia/Shanghai，本轮设备验证日期）。

本版修复九种运动与可选Polar H10在真机验证中发现的上传、暂存和恢复问题。三星已原位更新，并完成无H10的新增运动流程检查。

## 本版修复

- 九种运动各自的数据包均可通过上传文件名校验，旧走跑包和历史包继续兼容。
- “暂存到戒指”重开后保持手动下载选择及正确提示，重复状态和残留进度不会显示成正在下载。
- 更新App后可以继续上传旧版本已经冻结的数据包；来源版本、ZIP原字节和研究字段保持。
- 暂存段冷重开、尚未连接戒指时可正常放弃；二次确认取消保持原段，确认后只清理本段手机文件与任务。
- 新段开始等待期间不再显示上一段已完成记录的开始时间。

首页九种运动、三种收尾和H10可选性保持既定规则。走跑填写非负步数；其余七类无需计步。H10每段默认关闭。journal v14、manifest v8、Python 0.3.0及研究数据语义不变。

## 适用范围

本轮支持对无H10新增运动的操作闭环进行实际使用核对。所采短段是流程验证资料，研究质量保持`pending_review`，信号覆盖和采集边界仍需研究者核对。

当前没有真实H10。心率连接与HR/RR的数据路径、失败恢复及文件生命周期已有软件和模拟器验证；真实双设备连接、锁屏后台、断连返回和长时采集仍需硬件验收。10小时继续作为待实测目标，既有华为长时证据保持原版本范围。初次三星连接曾出现一次GATT 133并经手动重连恢复，详见E48。

操作规则见[被试说明](participant-guide.md)，数据契约见[多运动与心率](../specs/independent-step-collection/multisport-heart-rate.md)。
