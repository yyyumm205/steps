## 1. 已确认的目标与范围

被试首次填写编号 P001，之后打开 App 自动记住；连接戒指，选择走路或跑步及佩戴位置，开始并结束一次活动，填写本次计步器步数，手机先保存再自动上传到用户自己的清华云盘。Python 在本机同步、导入与解码。例如本次走了 562 步，同一 session 保存对应的戒指信号和数字 562。

独立名称与安装身份、本地编号、上述采集流程、移除旧平台登录/睡眠/评分/其他设备入口，均来自用户明确选择。完整闭环涉及总纲阶段 1–3，按可独立检查的切片推进；最近的开发步骤是补齐桌面基线，然后完成“独立安装＋本地编号＋采集准备页”。切片完成与整个 App 可交给被试使用分别验收。

### 编号和数据归属

研究者分配实验内唯一编号，被试照填，暂定使用原有校验范围：3–24 位英文字母或数字，去掉首尾空格，大小写视为相同。P001/p001 在归档中统一为 `p001`；界面展示已确认的编号。用户无需注册、密码或短信验证。

暂定 `participant_id` 与 `participant_name` 均采用规范化实验编号，使同一个编号在同一实验的不同手机上归为同一被试；随机 installation ID 只用于标识一次安装，session UUID 标识每次采集。相同编号由不同人误填会混入同一被试，编号发放表由研究者维护；离线登记只能检查格式，无法查询研究者名单。后端字段兼容须在 B04/B11 验证。

session 创建后保留编号快照。是否允许在设置中更换当前编号见 Q01；任何选择均只影响以后新建的 session。待上传记录继续按原编号传输，上传队列不依赖当前页面选择的编号。原位升级新版、重开 App 不应重新分配或清空编号。

卸载或清除应用数据后需要重新填写原编号；填写相同编号可继续同一被试的新采集，但原私有待传任务不会因此自动恢复。本规格的重启恢复指保留应用数据的进程/设备重启，任务待处理期间的卸载不作为恢复手段。

### 停止、填写步数与保存

主流程为“准备 → 启动中 → 采集中 → 停止确认中 → 待填步数 → 已保存步数 → 下载/本地保存 → 排队上传 → 上传完成”。异常进入对应的可恢复状态。

- 点击结束时发出停止命令；尚未确认停止时显示真实状态，重连后先查询戒指状态。同一 session 的停止不能因重复点击变成新采集。
- 暂定停止确认后显示步数输入页；“保存并上传”作为本次数字的确认按钮。填写时可以改，确认后先完成本地落盘，再启动耗时任务。这与用户提出的自动保存上传闭环对应，按钮和时机仍供审阅。
- 退出输入页保留“待填步数”，下次打开回到该 session；未确认的草稿与已保存数字区别显示。待填步数时保持戒指待传保护，新采集不得覆盖原始数据。
- 每次保存失败保留待处理状态及已有记录，允许重试；不能显示已保存或上传成功。
- 上传前的数字修改入口和锁定时机待 Q03 确认。至少允许在最终确认前修改；如已生成缓存 ZIP，修改后须使旧包失效并重建。首次发送前冻结该次内容与 ZIP，避免同一 session 的重试产生不同数字或哈希；服务器收到而手机未收到回执时，仍重试同一包。上传成功后原记录保持不变。

### 时间范围

步数与戒指信号覆盖同一段采集。开始/停止请求时间、戒指确认时间、实际样本首末时间和下载完成时间应分别保留，用验证记录核对。原版 `ended_at_ms` 取自下载/整理完成时刻的行为需要在新增采集状态中修正，不能沿用为活动结束边界。

以已确认的采集起止作为 session 范围，记录设备时间锚点和样本实际覆盖情况。不能仅凭手机回调到达时刻宣称硬件时间完全同步。正常操作建议站定准备、确认开始后活动、站定结束再读计步器；计步器清零或累计读数相减由 Q02 决定。边界不明的故障 session 保留原始数据并标明待研究者核对，不能作为已对齐参考样本验收。

## 4. 恢复与传输规则

| 中断位置 | 预期恢复规则 |
| --- | --- |
| 登记后重新打开 | 从本地恢复编号；不向旧用户服务验证 |
| 采集中断连/进程重启 | 恢复同一 session 和戒指，查询实际状态；确认开始时间丢失时记录异常，禁止以当前时间伪装原起点 |
| 结束命令未确认 | 恢复后查询采集状态；继续显示停止确认中或需重新连接，步数不能与不明结束边界一起标为可用样本 |
| 待填步数时退出 | 恢复输入任务及已落盘草稿；原 Flash 记录保持待传保护 |
| 步数已保存后重启 | 数字、来源、记录时间与归属一致；继续下载，不要求重新填写已确认步数 |
| 下载中断 | 使用原 session 和持久断点恢复，完成后校验；必要的重读不能改动步数 |
| 上传中断或设备重启 | 原记录与 ZIP 内容冻结，恢复任务或提供重试；系统强行停止期间可等手动打开后恢复，不承诺持续后台运行 |
| 更换当前编号 | 若 Q01 允许，仅对新记录生效；旧待传/已传记录不改归属 |
| 首次配置上传目标 | 仅为从未绑定目标且从未发送的本 App 记录绑定已配置的实验位置，再继续同一 session；已绑定或尝试上传的记录保留原目标，更换目标另行制定明确迁移规则 |
| 重复/冲突包 | 同 session 同内容跳过；同 session 不同内容报告冲突并保留原记录 |

新版本显式使用独立云盘测试位置与本机活动数据根目录。旧版数据迁移不属于本功能，已有文件保留。HEALTH 可能仍生成 PPG，原始字节完整保留；“界面只做计步”不代表固件已切换成仅 IMU 模式。
